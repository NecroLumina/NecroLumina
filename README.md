## Selected work

### FraudNetZW
A fraud-detection prototype for mobile-money transactions, with a FastAPI backend and React/Vite analyst console. It explores combining rule-based checks, behavioural analysis, machine learning, and graph signals to help identify potentially suspicious activity.

**Technologies:** Python, FastAPI, React, Vite, scikit-learn, NetworkX.
